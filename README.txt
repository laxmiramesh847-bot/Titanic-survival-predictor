TITANIC SURVIVAL PREDICTOR - LAXMI RAMESH TELI

Files:
- app.py: Streamlit application
- requirements.txt: Python dependencies

Run locally:
1. Install Python.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py
5. Open the local URL shown in the terminal.
6. Upload the Kaggle Titanic train.csv file in the app sidebar.

Deploy online:
1. Create a GitHub repository and upload app.py and requirements.txt.
2. Open https://share.streamlit.io/ and sign in.
3. Choose the repository, branch, and app.py as the main file.
4. Deploy. Streamlit will provide a public app URL.

The app is not hosted by this package. A public URL is created only after deployment.
